# Faisal Mabood Portfolio

Personal portfolio for Faisal Mabood, AI Engineer, Python Backend Engineer, and Data & AI Solutions Engineer.

## Local development

```bash
bundle config set --local path vendor/bundle
bundle install
bundle exec jekyll serve --livereload
```

Open `http://localhost:4000/` in a browser.

The production stylesheet is compiled from `assets/css/scss/main.scss` into `assets/css/main.css`.
